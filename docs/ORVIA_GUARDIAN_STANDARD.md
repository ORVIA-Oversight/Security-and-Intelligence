# ORVIA GUARDIAN — Estate Quality Standard

Guardian is the ORVIA estate watchkeeper.

Current ORVIA method:
OBSERVE → REVIEW → VERIFY → INTERPRET → ACCOUNTABLE

Retired public wording ending in ACT must not be reintroduced.

VERA:
IMPLEMENTED → VERIFIED → EFFECTIVE → SUSTAINED

Core rules:
- Human first. Human last.
- Evidence before assumption.
- Human judgement remains accountable.
- AI supports evidence, challenge and workflow; it does not autonomously make safeguarding, clinical, legal, disciplinary or culpability decisions.
- Public sites must retain visible trust, contact and commercial next-step routes appropriate to that product.
- ORVIA presentation must remain calm, premium, human, corporate and evidential; avoid gimmicky sci-fi / robot / neon-AI presentation.
- Closed is not fixed. Completion is not the end state.

Guardian states:
PASS — no material drift detected.
WARN — review needed; build can continue.
HOLD — non-negotiable regression detected.
